# Promotional artwork

A consistent visual family based on [dralfiegordon.com](https://dralfiegordon.com): white space, Geist typography, charcoal text and restrained blue accents.

- `cover.jpg`: 1280 × 640 pixels, suitable for the repository README and GitHub social preview.
- `cover.svg`: editable vector source with the font embedded. Its illustration is original and its example interfaces are illustrative.
- `OFL.txt`: the bundled Geist font licence, also retained inside the SVG. The font is separate from the repository's code licence.

Use the JPEG for sharing. Edit the SVG to update the copy or artwork, then render a new image at the same dimensions. No private account information, client assets or tracking is included in the artwork.

## Full collection

This folder includes the covers for all six tool repositories, the profile cover and four selected-work illustrations. `collection.jpg` shows the six tool covers together.

To download everything, use **Code → Download ZIP** on the [profile repository](https://github.com/dralfiegordon/dralfiegordon), unzip it, and open `assets/promo/`. Each named JPEG has a matching editable SVG.
